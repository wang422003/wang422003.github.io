LLM4EDUKG

Evaluating language model reasoning about prerequisite relationships and multi-hop dependencies in educational knowledge graphs.

LLM4EDUKG evaluates how pre-trained language models understand prerequisite relationships in educational knowledge graphs. The project provides four knowledge graphs and an evaluation pipeline for reasoning about knowledge components and multi-hop dependencies.
